# Styrofoam Factory ERP System — Part 8: Barcode System and Complete Traceability

Version: 1.0

## 1. Introduction

The barcode system is not implemented simply to identify products. Its objectives:

- Complete production traceability
- Worker accountability
- Faster data entry
- Prevention of manual typing errors
- Preventing workers from bypassing the ERP

Every important object receives a unique barcode. Workers scan instead of entering IDs. The barcode system connects every production stage into one continuous traceability chain.

## 2. Barcode Philosophy

Management wants to control the production process and ensure workers use the ERP for every important operation, so tasks begin by scanning whenever possible.

```
Extruder → Print Roll Barcode
  → Thermo → Scan Roll Barcode → Produce Bags → Print Bag Barcodes
  → Packaging → Scan Bag Barcode → Assign To Pallet
  → Warehouse → Scan Pallet Barcode
```

## 3. Objects That Receive Barcodes

**v1:** Rolls · Produced Bags · Wooden Pallets

**Future:** raw material containers, packaging material boxes, warehouse locations, machines, tools.

The database should allow future expansion without changing the existing barcode structure.

## 4. Roll Barcode

Printed immediately after production and attached to the physical roll; identifies the roll for its entire lifecycle.

Linked information: Roll Number · Production Date · Shift · Operator · Recipe Version · Color · Product Type · Roll Test Report · Thermo Production.

## 5. Produced Bag Barcode

Created automatically with each bag.

Identifies: Produced Bag · Roll · Thermo Production · Product Type · Color · Plate Count · Weight · Production Date · Assigned Pallet.

Used by the packaging worker to assign bags to pallets.

## 6. Wooden Pallet Barcode

Generated when a pallet is created.

Identifies: Pallet Number · Product Type · Color · Status · Assigned Bags · Inventory Status.

## 7. Barcode Workflow

```
Extruder Production → Create Roll → Print Roll Barcode
  → Thermo Operator → Scan Roll Barcode → Create Produced Bags → Print Bag Barcodes
  → Packaging Worker → Create Wooden Pallet → Print Pallet Barcode
  → Scan Pallet Barcode → Scan Produced Bag Barcode → Assign Bag To Pallet
  → Warehouse → Scan Pallet Barcode → Store Finished Goods
```

Each stage uses information created by the previous stage.

## 8. Worker Accountability

Every scan is associated with: Logged-in User · Date · Time · Shift · Device (future).

Management can therefore know who performed the operation, when, which shift, and which production stage. The ERP creates a complete audit trail for all barcode operations.

## 9. Traceability Chain (Backward)

```
Scan Pallet Barcode
  ↓ Display all bags assigned to that pallet
  ↓ Select one produced bag
  ↓ Display thermo production information
  ↓ Display roll information
  ↓ Display recipe version
  ↓ Display recipe ingredients
  ↓ Display raw materials consumed
```

## 10. Forward Traceability

A problem is discovered with Recipe Version 2.1. The ERP identifies:

```
Recipe Version → Produced Rolls → Produced Bags → Wooden Pallets → Future Customer Shipments
```

This allows the factory to locate all affected products.

## 11. Barcode Generation

Every barcode must be unique and **never reused**, even if an item is deleted or archived.

The barcode value may simply contain a unique identifier generated by the ERP. The exact format (Code 128, QR Code, etc.) can be selected during implementation — **the database design should remain independent of the barcode technology.**

## 12. Barcode Labels

Each printed label contains both a human-readable identifier and a machine-readable barcode:

```
ROLL-20260815-00125
[Barcode]
```

This allows workers to identify items even if the scanner is unavailable.

## 13. Barcode Scanning Rules

Workers should not manually type identifiers if scanning is possible — thermo scans the roll, packaging scans the bag, warehouse scans the pallet.

## 14. Audit Logging

Every barcode-related operation creates an audit record: User · Date · Time · Action · Item · Notes.

Example actions: `Barcode Printed`, `Barcode Scanned`, `Bag Assigned`, `Pallet Created`, `Inventory Stored`.

**These records must never be deleted.**

## 15. Future Barcode Enhancements

Wireless handheld scanners · Android scanning application · QR codes · warehouse location barcodes · automatic barcode printing · machine-generated production labels · customer shipment labels.

## 16. Business Rules

- Every Roll, Produced Bag and Wooden Pallet must have one barcode.
- Barcodes must be **unique across the entire ERP**.
- Barcodes must never be reused.
- Scanning a barcode should always retrieve the associated object.
- Every scan should be recorded in the audit history.

## 17. Module Summary

Barcodes connect every production stage into one continuous digital workflow:

```
Raw Materials → Recipe Version → Roll → Roll Test Report → Thermo Production
  → Thermo Test Report → Produced Bag → Wooden Pallet → Finished Goods Inventory → Future Shipment
```
